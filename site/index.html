功能

为 BOM 核对而生

不再写死核对规则，不再依赖表头名称：读懂表格内容，再逐项比较。

按内容识别每一列

位号列看「R1,R2」这样的位号，用量列看是否与位号数一致，料号列看唯一编码，描述列看较长文字。表头叫什么都行，没有表头也能读。

  • 支持 .xlsx / .csv / .txt，表头前可以有标题行
  • 品名 + 规格等多列描述自动拼接，位号续行自动归位
  • 鼠标停在卡片上即可查看每列被识别成什么

描述只比参数，其余一字不差

物料描述只比较英文与数字组成的参数：中文名称多一个字、少一个字或一长一短都算一致。用量、位号和其他列必须百分之百相同。

  • 差异单元格填色，不同的字符加粗高亮
  • 位号列出 B+C 缺少、多出以及挂在其他料号下的
  • 名称不同或无表头的列按内容自动配对比较

AI 核对，一个开关

在设置里接入 OpenAI 兼容接口或 Anthropic，在核对页打开开关。每次核对后，AI 给出总结与逐条发现，例如等价写法、用量与位号矛盾。

  • 支持 OpenAI、DeepSeek、通义千问、Kimi、Ollama、vLLM 等
  • AI 标记的料号青色标识，点击发现跳到对应料号

STEP 1

安装软件

在下方 下载 区域选择与设备对应的安装包。

平台安装方式
Windows运行 SMT-FAI-版本-windows-x64-setup.exe，按当前用户安装，无需管理员权限。ARM 设备选 arm64。也可下载 zip 绿色版解压即用。
Android安装 android-universal.apk（或与设备架构对应的 APK）。首次安装需在系统中允许「安装未知来源应用」。

STEP 2

导入文件

把文件拖到核对页顶部对应的卡片上，或点击卡片选择文件。

卡片说明
A-BOM核对的基准，必需。
B-BOM必需。
C-BOM可选。有 C-BOM 时，B 与 C 先合并（同一料号用量相加、位号合并），再与 A-BOM 核对。

不需要固定的表头：料号、描述、用量、位号按内容识别，其他列（品牌、类别等）也会参与比较。卡片显示「检查通过」以及料号数、列数；鼠标停在上面可查看每列的识别结果与提示。

STEP 3

核对规则

项目规则
物料描述只比较英文字母与数字组成的参数（区分大小写、顺序不限）；中文名称多一个字、少一个字或长短不同都视为一致。
用量 · 位号必须完全相同。
其他列两边都有的列逐字比较；只有一边有的列不比较，并在筛选栏旁列出。
配对依次按相同料号、共有位号（支持拆分 / 合并）、相同厂商料号、登记的替代料号、类别与参数，以及本地语义模型的建议。
例：贴片电阻 10K ±1% 0402 与 贴片电阻器，10K ±1% 0402 一致；10uF 6.3V 与 10uF 10V 不一致。
STEP 4

查看结果

  1. 点 开始核对（F5）。顶部统计卡显示 PASS / NG / 需复核 / 未匹配 / 认可替代料 数量，点击卡片筛选；无法确认的一律「需复核」。
  2. 表格中不一致的单元格填色，不同的字符加粗高亮；位号标出 B+C 缺少（缺）和多出（多）的。
  3. 点击一行，右侧逐列对比 A-BOM 与 B+C 的值，并显示来源行号。
  4. 按料号、位号或描述搜索，按结果筛选。
  5. 每次核对自动保存到 核对记录（右上角时钟图标）：原始文件副本、SHA-256、结果与当时的报告，可按文件名、料号或描述长期查询追溯。
  6. 在 设置 → 核对与输出 选择参与核对的字段、报告包含的列和报告列出的结果。
STEP 5

AI 核对

  1. 打开「设置 → AI 核对」，选择 OpenAI 兼容（OpenAI、DeepSeek、通义千问、Kimi、Ollama、vLLM 等）或 Anthropic。
  2. 填写接口地址（留空为官方地址）、API Key 与模型，点 测试连接。
  3. 在核对页打开「AI 核对」开关。之后每次核对完成都会自动分析，结果显示在表格右侧。
  4. AI 标记的料号带青色标识；点击一条发现即可跳到对应料号。
AI 核对会把两份 BOM 的料号、描述、用量和位号发送到你配置的接口。涉及保密资料时请使用公司内部部署的模型。
STEP 6

导出与快捷键

点 导出 Excel（Ctrl+E）保存核对报告：每个料号一行，两边的描述、用量、位号和其他列并排，结果按状态填色，差异单元格填黄色，AI 说明填青色；开启 AI 时附带「AI 分析」工作表。

常见问题

还有疑问？

文件会上传到服务器吗？

本地核对不会：BOM 只在本机读取和处理，报告保存在你选择的位置。只有打开 AI 核对时，核对数据才会发送到你在设置中配置的 AI 接口。软件另外只在检查更新时访问 GitHub Releases。

表头名称和我们的不一样，能识别吗？

可以。料号、描述、用量、位号按单元格内容识别，表头写法不同甚至没有表头都能读取。鼠标停在导入卡片的状态上，可以看到每一列被识别成了什么。

描述只差几个中文字，为什么还显示差异？

说明英文或数字参数不同，包括大小写（如 10K 与 10k）。不同的字符会加粗高亮。中文部分本身不参与比较。

AI 核对支持哪些模型？

任意 OpenAI 兼容接口（OpenAI、DeepSeek、通义千问、Kimi、智谱、Ollama、vLLM 等）和 Anthropic。在「设置 → AI 核对」中填写地址、Key 和模型，点「测试连接」确认。

Android 提示「签名不一致」或「与现有软件包冲突」？

1.3.0 及更早版本使用的是临时调试签名。从 1.4.0 起所有 APK 使用同一正式签名，请先卸载旧版本再安装一次，之后的版本都可以直接覆盖升级。

Windows 安装时出现 SmartScreen 提示？

安装程序暂未进行商业代码签名，首次运行可能提示「Windows 已保护你的电脑」。点击「更多信息 → 仍要运行」即可。安装包均由公开的 GitHub Actions 构建。
