功能

为 SMT 产线首件检验而生

从文件导入到坐标输出，每一步都为产线工程师的真实流程设计。

拖入文件，立即检查

T100 BOM、A 面与 B 面站位表直接拖入卡片。每个文件导入后自动识别工作表和列，并立即显示检查结果。

  • 支持 .xlsx / .csv / .txt，自动识别表头位置
  • 插件位置中的换行、逗号、空格和范围写法都能识别
  • 替代料可写在下一行或「关联料号」列

每一处差异，都有原因

PASS、NG、已排除物料、替代料分区统计。NG 项逐条写明原因：缺少位号、多出位号、数量不符、不在 BOM 中、描述不一致。

  • 人工确认与备注，确认记录写入 Excel 报告
  • 差异清单汇总 BOM、站位表与坐标之间的全部不一致
  • 按面别、结果、确认状态筛选，料号与位号模糊搜索

一键生成 FAI i450 坐标

导入 EDA 坐标文件，单位自动识别，按 FAI i450 导入模板输出 Location、X、Y、Angle、Specification、PartNo、Layer、Qty。

  • mm / mil / inch 自动识别，也可手动指定
  • 列顺序、表头、分隔符、编码、小数位均可自定义
  • 生成检查：位号匹配、重复位号、坐标有效性与面别一致性

PCB 导航图，所见即所贴

按真实尺寸和角度绘制每一个元件，NG 位号红框标出。2D 平面或 3D 立体视图，缩放、旋转、镜像查看底面。

  • 拥挤元件自动缩小显示，坐标始终不变
  • 实物配色、元件类型、核对结果三种着色
  • 悬停查看位号、坐标、料号；右键更换元件模型

使用教程

五分钟上手

从安装到输出 FAI 坐标文件的完整流程。软件内「设置 → 使用说明」也可随时查看，或点击右上角问号重新开始新手引导。

STEP 1

安装软件

在下方 下载 区域选择与设备对应的安装包。

平台安装方式
Windows运行 SMT-FAI-版本-windows-x64-setup.exe，按当前用户安装，无需管理员权限。ARM 设备选 arm64。也可下载 zip 绿色版解压即用。
Android安装 android-universal.apk（或与设备架构对应的 APK）。首次安装需在系统中允许「安装未知来源应用」。
Linuxsudo apt install ./SMT-FAI-版本-linux-x64.deb，或解压 tar.gz 运行 smt_fai。
以后升级直接安装新版本即可覆盖，设置与核对规则会保留；软件也会在启动时自动提示新版本。
STEP 2

导入文件

打开「文件导入」页，把文件拖到对应卡片上，或点击卡片选择文件。BOM 与站位表 A 为必需，单面板可不导入站位表 B。

文件需要的列
T100 BOM料件编号、品名（规格）、组成用量、插件位置。其他列会被忽略。
站位表 A / B站位、料号、物料描述、数量、位号。替代料可放在下一行（站位与位号留空），或写在「关联料号」列。
坐标文件位号、X、Y、角度、面别（可选）。在「CAD 坐标」页导入，支持常见 EDA 导出的 .csv / .txt / .xlsx / .pos。

每张卡片会立即显示「文件检查结果」：格式、工作表、识别到的列和数据数量。显示「检查通过」后点底部的 开始核对（F5）。

STEP 3

核对与人工确认

  1. 顶部统计卡显示 PASS / NG / 已排除物料 / 替代料 / 差异清单 数量，点击卡片即可筛选该类。
  2. 点击表格中的料号，底部明细卡列出 BOM 用量、SMT 数量、面别、站位以及每一条 NG 原因和说明。
  3. 核对无误的项目点「确认」，可填写备注；表头的「人工确认」可一次确认当前列表。
  4. 点「差异清单」查看 BOM、站位表 A/B、坐标文件之间的全部不一致。
  5. 点右上角 导出 Excel（Ctrl+E）保存核对报告，确认记录与备注会一并写入。
STEP 4

生成 FAI 坐标

  1. 打开「CAD 坐标」页，点「导入文件」选择坐标文件。
  2. 坐标单位默认自动识别，若识别不准可选 mm、mil 或 inch。
  3. CAD 格式默认 FAI CAD（.xlsx），与 FAI i450 导入模板一致；点齿轮可调整列顺序、表头、分隔符、编码和小数位。
  4. 右侧「生成检查」显示位号匹配、重复位号、坐标有效性和面别一致性。点 生成 CAD（Ctrl+G）保存文件。
存在未确认的 NG 项时会先提示；全部 NG 人工确认后生成不再提示。
STEP 5

PCB 导航图

  1. 数据源：使用当前核对数据，或直接打开已生成的 CAD 坐标文件。
  2. 显示面：所有面 / TOP 面 / BOT 面；查看底面时建议打开「镜像」。
  3. 视图：左转、右转 90°，适应窗口，复位，全屏（F11，Esc 退出）。滚轮或双指缩放，拖动平移，双击适应窗口。
  4. 元件显示：2D 平面或 3D 立体。3D 默认俯视，右键拖动旋转、倾斜视角，右下角一键切换俯视 / 斜视。
  5. 着色：实物配色、元件类型或核对结果；「配色」可自定义颜色与板子背景。
  6. 鼠标悬停查看位号、坐标、料号；右键（触屏长按）元件可更换元件模型。
STEP 6

规则与设置

点击右上角设置按钮：

  1. 核对规则：排除关键字（如 PCB、锡膏、标签）、排除料号前缀、编程件关键字、替代料对照表（原料号=替代料1,替代料2）、忽略位号和数量检查开关。
  2. 元件库：浏览 63 种元件模型，查看按位号、料号或封装指定的自定义模型。
  3. 导航图配色：元件颜色、板子背景、2D / 3D 默认显示。
  4. 外观：主题、界面缩放与语言。软件更新：检查更新与自动检查开关。
STEP 7

常见问题

还有疑问？

文件会上传到服务器吗？

不会。BOM、站位表和坐标文件都只在本机读取和处理，报告也保存在你选择的位置。软件只在检查更新时访问 GitHub Releases 获取版本信息。

Android 提示「签名不一致」或「与现有软件包冲突」？

1.3.0 及更早版本使用的是临时调试签名。从 1.4.0 起所有 APK 使用同一正式签名，请先卸载旧版本再安装一次，之后的版本都可以直接覆盖升级。

Windows 安装时出现 SmartScreen 提示？

安装程序暂未进行商业代码签名，首次运行可能提示「Windows 已保护你的电脑」。点击「更多信息 → 仍要运行」即可。安装包均由公开的 GitHub Actions 构建。

支持哪些文件格式？旧版 .xls 可以吗？

支持 .xlsx、.csv、.txt；坐标文件另支持 .pos 等常见 EDA 格式。旧版 .xls 请在 Excel 中另存为 .xlsx 后导入。

替代料怎么写才能被识别？

站位表中可把替代料放在主料的下一行（站位与位号留空），或写在「关联料号」列；也可以在「设置 → 核对规则 → 替代料」中按 原料号=替代料1,替代料2 维护对照表。

导航图上的元件模型不准确怎么办？

导航图按位号前缀、封装名和规格描述自动识别模型。识别不准时，右键（触屏长按）该元件即可改用其他模型，可按位号、料号或封装应用，之后自动生效。
