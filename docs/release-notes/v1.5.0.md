## SMT-FAI 1.5.0

### 全新界面
按新的设计稿重做了全部界面，功能和操作方式保持不变。

- **整体风格**：柔和渐变背景、大圆角卡片、玻璃质感的顶部导航胶囊和圆形按钮；统一使用 Inter 字体和线性图标；浅色 / 深色主题同步更新。
- **顶部栏**：Logo、居中的「文件导入 / BOM 核对 / CAD 坐标 / PCB 导航图」切换、语言、主题、帮助和设置按钮；底部状态栏显示核对状态、已导入文件数和快捷键（F5 开始核对、Ctrl+E 核对报告、Ctrl+G 生成 CAD）。
- **文件导入**：居中标题和步骤进度；BOM、站位表 A、站位表 B 三张导入卡片，导入后直接显示文件信息和检查结果；底部悬浮操作条显示当前进度和「开始核对」按钮。
- **BOM 核对**：文件信息卡 + 导出 Excel；PASS / NG / 已排除物料 / 替代料 / 差异清单统计卡（点击筛选）；搜索与面别、核对结果、确认状态筛选；圆角表格和底部明细卡，人工确认和备注保留。
- **CAD 坐标**：坐标文件、单位、CAD 格式、生成操作四张卡片；坐标预览表；右侧生成检查和文件信息。
- **PCB 导航图**：数据源、显示面、视图、着色、元件显示分组工具栏；圆角画布、带安装孔和阴影的 PCB 板；玻璃质感的图例、缩放按钮、3D 视角控制和全屏控制条。
- **设置**：左侧导航卡片 + 右侧内容卡片；元件库、使用说明、核对规则、新手引导提示框同步更新样式。

### 其他
- 平板横屏等较矮的窗口中，BOM 核对页整体可滚动，表格保持足够高度；窄窗口下表格列宽自动收缩。
