## SMT-FAI 3.1.0：更少误判、A/B/C-BOM、可配置核对、更小的本地模型、核对记录

### 减少误判
用真实的站位表与 T100 BOM 逐条复现后修正了三类误判（同一组文件从 57 PASS / 34 NG 变为 91 PASS / 0 NG）：
- **替代料号**：站位表「关联料号」常写本行自己的料号，另一份为空，以前判为 NG。现在替代料按集合比较、去掉本行料号；两边登记的替代料不同时只提示，不影响结果。
- **固定宽度折行**：T100 等 ERP 导出会在单元格内按固定宽度换行，把词拆开（如「13x1↵5mm」）。现在这类折行会接回原文；描述只差空白时视为相同。
- **不上线的物料**：锡膏、标签、碳带、PCB、组件行（用量 0 或小数）在站位表上本来没有，未匹配时标注原因「辅料、包装、PCB 或组件行」，风险为低。

### 名称与界面
- 三份文件改名为 **A-BOM**（基准）、**B-BOM**、**C-BOM**（可选，与 B-BOM 合并为 B+C）。
- 结果「通过 / 不一致」改为 **PASS / NG**。
- 结果表料号列加宽，长料号换行完整显示；统计卡下方不再留空白，筛选栏移到操作面板旁。

### 核对与输出可配置（设置 → 核对与输出）
- 选择参与核对的字段：描述、用量、位号、厂商料号、厂商、替代料、贴装标记、层级、其他共有列。关闭的字段仍用于配对，但不会导致 NG 或需复核；结果页与报告会写明哪些字段未核对。
- 选择报告包含的列和列出的结果（例如只输出 NG 与需复核）。

### 多种本地模型，低配置电脑也能用
- 不开本地模型时程序照常完整核对；本地模型只为规则配不上的物料推荐候选（结果一律需复核）。
- 设置 → 本地模型可任选一个匹配模型：

| 模型 | 下载 | 约需内存 |
| --- | ---: | ---: |
| Granite-Embedding-278M（默认，推荐） | 209 MB | 340 MB |
| Granite-Embedding-107M（轻量，最快） | 115 MB | 260 MB |
| EmbeddingGemma-300M（匹配最多） | 318 MB | 360 MB |
| Qwen3-Embedding-0.6B（原默认） | 610 MB | 710 MB |

- 实测新的默认模型比原来的更快、内存减半、配对更多，且无配错；已下载 Qwen3 的用户无需重新下载。
- Windows 离线完整安装包改为自带 Granite-278M，体积减小约 400 MB。

### 核对记录
- 每次核对自动保存：原始文件副本及 SHA-256、模式与模型、未核对的字段、各结果数量、逐行结果和当时的 Excel 报告。
- 右上角时钟图标打开核对记录：按文件名、料号或描述搜索全部记录；可重新载入并核对（文件被改动时拒绝）、导出当时的报告、删除。

### 升级说明
- 演示文件改名为 `demo_A_BOM.xlsx`、`demo_B_BOM.xlsx`、`demo_C_BOM.xlsx`。
- 替代料号不同不再判 NG，只作提示；如需严格比较，可在报告中查看提示原因。
