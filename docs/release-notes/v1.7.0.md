## SMT-FAI 1.7.0

### 界面
- **页面栏移到左上角**：以绘制图标显示 BOM 核对 / CAD 坐标 / PCB 导航图，鼠标悬停显示名称；点击右侧箭头可展开显示页面名称（会记住选择）。去掉左上角的 Logo 和名称。
- **设置按钮改为齿轮图标**。
- **文件导入合并到 BOM 核对页顶部**：T100 BOM、站位表 A、站位表 B 三张紧凑卡片（可拖入或点击导入，显示检查结果），右侧是「开始核对 / 导出 Excel / 清空」。站位表 A / B 改为文档图标，颜色不变。
- **BOM 核对**：统计卡片缩小、缩窄；点击核对结果后，问题卡片显示在表格右侧，与表格上下对齐。
- **人工确认**：PASS 结果无需人工确认；NG、已排除物料、替代料需要人工确认。
- **CAD 坐标**：顶部四张卡片按内容宽度显示，不再拉满整行。
- **PCB 导航图**：
  - 去掉标题和工具栏分组小字，工具栏收窄为一行图标；镜像、旋转、复位、配色等折叠在「…」中，点击展开。
  - 着色方式与 2D / 3D 改为下拉选择。
  - 去掉标题行，导航图默认显示范围更大，板子尽量铺满画布。
  - **新增位号定位**：在工具栏右侧输入位号并回车，导航图自动缩放平移到该元件，并发光闪烁提示；元件在隐藏的一面时自动切换为显示所有面。
- **设置**改为常见软件的列表样式：一行一项，点击进入二级页面，左上角返回设置列表；「软件更新」合并到「关于」页面。
- **首次使用必须完成新手引导**（首次运行时不显示「跳过」，之后从帮助按钮重新开始时可跳过）。

### 手机与平板
- 手机底部导航栏采用 Apple「液态玻璃」风格：悬浮胶囊、背景模糊增强、高光边缘，当前页显示玻璃透镜；设置也作为一个标签页。
- 安卓平板横屏使用与电脑端相同的界面，竖屏使用手机端风格。
