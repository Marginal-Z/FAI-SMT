## SMT-FAI 1.6.0

### PCB 导航图：按真实元件识别与绘制
不再只针对某一类元件或某一个产品，换用其他产品的坐标文件和 BOM 也能自动识别，无需手动修改。坐标和角度始终保持不变。

- **自动识别封装参数**：从坐标文件的封装名和 BOM 物料描述中读取封装类型、引脚数、排数、间距和本体尺寸。支持常见写法：
  - EDA 封装名：`SOIC-8_3.9x4.9mm_P1.27mm`、`QFN-32-1EP_5x5mm_P0.5mm`、`PinHeader_2x05_P2.54mm`、`JST_SH_..._1x04_P1.00mm`、`CONNEC4_125MM`
  - 常用简称：`SOT-23-5`、`SOT563`、`SC70-4`、`TSSOP20`、`MSOP_8`、`LQFP-100`、`VFBGA96`、`WLCSP-1.47×2.21-15B`、`DFN1006`
  - 中文 BOM 描述：`FPC连接器 24PIN*0.5mm间距`、`板对板 2*5PIN 间距0.5mm`、`排母 2*10PIN 1mm`、`PH2.0 4P`、`43pin CSP`
- **按真实引脚数绘制**：连接器是多少 PIN 就画多少个触点（FPC、BTB 双排、排针排母、线对板），IC 按实际引脚数画出各边引脚（SOP / TSSOP / MSOP / QFN / DFN / QFP），SOT-23 区分 3 / 5 / 6 脚，排阻、LED、晶振（2 脚 / 4 脚）、按键、继电器等同样按引脚数绘制。
- **尺寸更准确**：连接器长度 = 触点数 × 间距；IC 按封装标准尺寸（如 SOIC 3.9 / 7.5 mm 体宽、TSSOP 4.4 mm、LQFP-64 为 10 × 10 mm）；功率电感 4020 / 252012 / 0420 等尺寸码；BGA / CSP 按球数估算。
- **识别规则更稳**：封装名优先于描述（封装名代表板上实际焊盘）；描述含「屏蔽框 / 螺柱 / 铜柱」时按结构件显示；封装名含 MARK 但描述是电阻电容时不再误判为光学点。
- 新增「射频同轴座 IPEX」元件模型，元件库共 64 种。

### 手机与平板自适应布局
安卓端不再把电脑界面整体缩放，而是按屏幕宽度使用专属布局。
- **手机**：顶部精简标题栏，底部导航栏切换四个页面；BOM 核对页统计卡横向滑动、结果以卡片列表显示，点选物料后从底部弹出明细；CAD 坐标页输出行以卡片显示全部字段；PCB 导航图工具栏改为一行图标按钮，图例移到顶部；文件导入页「开始核对」固定在底部；设置项改为上下排列。
- **平板**：按设备实际尺寸布局（竖屏单列、横屏双栏），控件随屏幕密度适当放大；PCB 导航图在平板上使用紧凑工具栏，所有按钮都能直接点到。
