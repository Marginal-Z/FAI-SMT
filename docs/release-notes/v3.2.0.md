# SMT-FAI 3.2.0：更严格的 BOM 规则、可验证的模型调用、元件方向提醒

## BOM 核对规则修复

- 相同料号在同一文件或 B+C 中出现多行时，检查每条来源记录的描述、厂商等属性和贴装标记；后续行的冲突不再被第一行遮蔽。详情与 Excel 保留冲突值及来源行。
- 检查同料号、跨料号和 B+C 的重复位号，即使两侧都重复也不能判 PASS。
- 用量按完整单元格解析：支持科学记数法和明确千分位；无法确认的分数、表达式、负数及错误分隔符进入复核。空用量、用量与位号数不符、单侧缺少要求核对的列也会明确提示。
- 修复 Not fitted 表头被反向解释、未知贴装标记默认为已贴装、合并后丢失层级的问题。
- 中文颜色、极性和电容类型等已知区分特征参与核对；特征缺失进入复核。X5R/X7R/C0G 等可作为陶瓷介质证据，避免仅因名称写法不同误报。
- MPN 和替代料自动配对要求双向唯一；语义建议检查双向歧义，并校验向量数量、维度及数值。
- 修复陌生表头后有空行时将表头读成物料的问题，补充 SKU 料号表头识别。

## 本地模型状态与真实推理自检

- 修复启动时没有刷新模型文件状态的问题：已下载并开启的模型，重启后无需先打开设置页才能被识别。
- 核对页分别显示未启用、模型未就绪、本次无需调用、云端模式、正在运行、成功或失败；实际调用后显示处理描述数、候选数及耗时。
- 设置 → 本地模型增加“运行推理自检”，实际加载模型并请求向量。自检成功与本次 BOM 是否调用模型分别记录。
- Excel 和历史元数据保留本次模型调用证据；失败时保留规则结果并明确提示。模型打开前校验实际 SHA-256。
- 重载或清空文件会使旧推理结果失效，避免覆盖新文件；同一原生模型引擎不再并发处理核对任务。
- 当前核对使用向量模型给双侧未匹配项推荐候选，候选保持“需复核”；可选语言模型尚未接入当前核对流程。

## 元件方向核对提醒

- 根据二极管/LED、有极性电容、IC/晶体管、排阻、连接器等证据，提示核对极性、Pin 1、缺口、卡扣或机械方向。
- 电容类型不明、双向保护器件及未知类别有针对性的确认提示；普通电阻、明确的无极性电容和 DNP 不泛化报警。
- 原因筛选新增“方向核对提醒”；行内、详情和 Excel 显示提醒、依据及位号，重复料号的后续描述同样参与提醒。
- BOM 一致不代表实际贴装方向已确认，仍需对照具体规格书、PCB 丝印及首件实物。

## 隐私与验证

- 修复独立 AI 分析未应用隐私选项的问题；料号别名、位号数量和其他列关闭选项会应用到分析请求，返回别名再映射回实际料号。描述自由文本仍需自行确认是否含敏感信息。
- 异步模型/云端核对尚未结束时，报告明确标注未完成，最终阶段再归档。
- 本地验证：122 项通过、7 项因缺少其他模型或客户样本跳过；包含真实 Granite-Embedding-107M GGUF 推理、启动状态恢复及 390/800/1440 宽度界面检查。静态分析、Linux x64 Release 构建和隔离启动检查通过。
- 1000 份读取生成样本及 400 份保留样本完成评估；生成器结果不代表真实生产准确率。陌生 DNP 表头、人工列映射、客户 BOM 固定回归集等剩余事项见 [审查报告](https://github.com/Marginal-Z/FAI-SMT/blob/v3.2.0/docs/reviews/2026-11-09-bom-review.md)。

## 升级

直接安装对应平台的新版本即可覆盖升级，保留原有设置。模型下载后仍需开启“核对时使用本地模型”；仅当两侧都有规则无法配对的物料时才会实际调用。
