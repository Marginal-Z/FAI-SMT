# SMT-FAI 3.3.1

核对页重新排版，重点解决普通笔记本窗口中顶部占高、结果被推到下方，以及小窗口中难以看到判定的问题。

- **取消圆角卡片**：应用内区域统一直角、无卡片阴影；统计栏和物料清单使用分隔线，手机底部导航改为平面直栏。现代 / 工业配色均使用直角。
- **文件与操作分区**：三份文件使用统一紧凑布局，开始核对、模式、导出与清空集中到工具栏，取消右侧占高的操作卡片。
- **结果优先**：桌面筛选栏固定在表格上方，结果独立滚动；顶部设置有明确的滚动边界。结果列前移到料号旁，较窄窗口可直接看到判定；较长的翻译与 AI 标记可换行。
- **统计与状态更紧凑**：六个统计项都能直接访问。模型使用记录改为短摘要，耗时以秒显示；宽工作区中模型与方向摘要并列。
- **方向提醒按需展开**：保留元件/位号数量，明细、类别和人工核对说明按需展开。筛选按钮显示启用状态；方向筛选会解除只看 AI 发现的限制。
- **小窗口与手机**：不足 1000 像素的工作区使用物料清单。核对完成或分析中折叠文件区、模型选项；文件提示仍保留，手机筛选按需展开。分析进度与取消操作保持可见，详情关闭按钮保留足够触摸面积。
- **缩放与状态**：调整窗口或切换布局时保留当前筛选。物料详情在较窄桌面以侧面浮层展示，避免把表格继续向下推。

本次调整界面组织，继续要求本地模式用 Qwen3-4B 完成全部物料分析后才输出结果；模型缺失或失败时不回退显示规则结果。语言模型仍需单独下载，`full` 安装包不含 Qwen3-4B。

验证与截图见 [界面验证记录](../reviews/2026-11-10-check-layout.md)。
