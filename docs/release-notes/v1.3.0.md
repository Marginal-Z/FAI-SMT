## SMT-FAI 1.3.0

- 文件导入页按新设计重做，内容铺满整个窗口：三张导入卡片带序号、必需 / 可选标记和说明（?）。点击选择文件，Windows / Linux 上也可直接把文件拖到卡片上导入或替换。下方「文件检查结果」以表格列出每个文件的文件名、格式、数量、工作表、识别列和检查状态。顶部模块标签在宽屏下全部显示名称。
- 元件库：PCB导航图新增 63 种元件模型，覆盖市面上大多数贴片元件。包括贴片电阻 / 排阻 / 热敏 / 压敏、MLCC / 钽 / 聚合物 / 铝电解电容、叠层 / 一体成型 / 绕线电感、磁珠、共模电感、变压器、SOD / SMA / 玻封二极管、贴片与 PLCC LED、SOT-23 / SOT-89 / SOT-223 / TO-252 / TO-263 / DFN 功率封装、SOP / QFP / QFN / BGA / WLCSP / 屏蔽模块、无源 / 有源 / HC-49 晶振、FPC / BTB / 线对板 / 排针 / Type-C / Micro USB / USB-A / SIM / TF / RJ45 / DC 座 / 弹片、轻触 / 侧按 / 拨动开关、蜂鸣器、MEMS 麦克风、继电器、纽扣电池座、屏蔽框、散热片、安装孔、测试点和 Mark 点等。
- 元件绘制更真实：按实物构造分层绘制，包括端电极、塑封体、引脚、1 脚标记、印字、透镜、线圈、金属壳、针脚和卡扣，3D 视图中每层都有受光侧壁。新增「实物配色」（默认），元件放在绿色阻焊板上；「元件类型」「核对结果」配色仍可选。
- 元件识别依据位号前缀、封装名和规格描述。识别不准时，在 PCB导航图中右键（触屏长按）元件即可从元件库选择模型，可应用于此位号、此料号或此封装。设置中的「元件库」可浏览全部模型并管理这些规则。
- 设置新增「使用说明」：快速开始、各模块用法、快捷键和常见问题。标题栏新增帮助按钮。
- 新手引导：首次启动时逐步介绍导入 BOM、站位表、开始核对、各功能模块和使用说明，可随时跳过，也可在使用说明页重新开始。
