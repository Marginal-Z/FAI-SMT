## SMT-FAI 1.2.2

- CAD 坐标恢复输出全部位号（撤回 1.2.1 中跳过非 SMD / 机构件的改动）。
- 顶部模块改为图标标签，选中时展开显示名称；顺序为 文件导入、核对、CAD坐标、PCB导航图。
- 设置改为全屏二级页面（右上角齿轮进入，「返回」或 Esc 退出），核对规则移入设置。
- 文件导入：去掉功能区里重复的导入按钮，只保留「开始核对」「清空」；三个文件区块横向铺满。
- 核对：NG、替代料、已排除物料、PASS 四个区以一排卡片显示，点击卡片查看该区明细，默认不展开。
- CAD坐标：坐标文件导入区块移到功能区右侧，坐标单位也在此页。
- PCB导航图：可直接打开已生成的 CAD 坐标文件查看；新增「复位」和「全屏」（F11 / Esc）。
