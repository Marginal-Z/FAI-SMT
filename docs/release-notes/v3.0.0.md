## SMT-FAI 3.0.0：智能 BOM 核对

3.0 把核对引擎改为通用的智能核对：不依赖固定的文件结构、料号或表头，自动理解未知 BOM、为两份 BOM 的物料配对、严格校验参数；无法可靠判断的物料保留为「需复核」，不会为了提高通过率而猜测。

### 三种核对模式
- **本地**：完全离线、不需要 API Key。
- **混合**：先本地核对，再把无法确定的物料交给云端 AI，云端结论经程序交叉校验。
- **云端**：由云端 AI 识别字段并配对物料，程序校验记录覆盖、引用和每项数值；失败、截断或不完整时不显示完成。

### 五种结果，每条都有依据
- 通过、不一致、需复核、未匹配、认可替代料。
- 每条结果带原始文件、工作表和 Excel 行号，匹配依据（相同料号、共有位号、厂商料号、登记的替代料、类别与参数、语义模型、云端）与置信度，以及原因。
- 风险等级（高 / 中 / 低），可按结果、风险、原因筛选。

### 更聪明的读表
- 按内容识别料号、描述、用量、位号，以及厂商料号、厂商、替代料号、BOM 层级、贴装标记（DNP）；表头可以是任何语言或没有表头。
- 合并单元格、两行表头、多工作表、引号内换行的 CSV、纯数字料号、品名 + 规格分列。
- 自动识别物料类别（电阻、电容、IC、连接器、结构件、包装件等 24 类）。

### 严格的参数校验
- 参数按数值比较：10K = 10kΩ = 10000Ω，0.1uF = 100nF，4K7、49.9R、1/16W、C0G = NPO 都能识别，标注「数值等价」。
- 型号等含数字的内容必须一致；颜色、NPN/PNP 等区分性的词必须一致；表示类别的通用词和不同语言的写法可以不同。
- 用量、位号和两边都有的其他列必须完全一致；贴装标记和层级按含义比较。
- 一行拆成两行、两行合成一行、换了料号的物料都能通过位号配上；未登记的替代关系不会被当成认可替代料。

### 本地模型
- 设置 → 本地模型：下载 Qwen3-Embedding-0.6B（约 610 MB，Apache-2.0），断点续传、ModelScope / Hugging Face / hf-mirror 多镜像、SHA-256 校验。
- Windows 新增**离线完整安装包**（`-full-setup.exe`），自带本地模型，安装即用。
- 用于为换了料号、没有位号的物料寻找对应项（结果只会是需复核）。实测语言模型（Qwen3-4B）读列不如程序准确，因此默认不使用，可选下载。

### 云端 AI
- DeepSeek、OpenAI、Anthropic 与任意 OpenAI 兼容接口；价格可改，统计 Token 与费用；请求日志；超时、重试、限流、取消。
- API Key 改为保存在系统安全存储中；2.0 设置文件里的明文 Key 会自动迁移并删除。
- 可以选择不发送料号原文、位号列表和其他列。

### 报告
- Excel 报告新增来源行、匹配依据、原因、风险、标准化参数、云端说明，以及「汇总」工作表；核对未完成时表头醒目提示。

### 其他
- 界面去掉紫色，AI 相关颜色改为青色。
- 5000 行 BOM 读入约 0.3 秒、核对约 0.5 秒。

### 升级说明
- 结果分类变化：原来的「一致 / 有差异 / 仅单 BOM / 仅 A+B」改为五种结果。
- 描述规则变化：参数按数值比较（10K 与 10k 视为相同并标注），只表示类别的通用英文词可以与中文写法不同。
- 2.0 的 AI 设置会自动迁移；请到「设置 → AI 核对」确认接口与 Key。
