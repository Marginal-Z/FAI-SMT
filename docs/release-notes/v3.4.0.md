# SMT-FAI 3.4.0

## 桌面工作区

核对页改为桌面软件式工作区：顶部操作栏与筛选栏、中央结果表格、可收起和拖动调整宽度的右侧检查面板。文件、模型、方向提醒、物料详情和云端 AI 各有面板，取消顶部大块统计区域。窗口宽度达到 840 像素时使用表格；更窄窗口与手机继续使用清单。保留直角界面。

结果表增加“问题 / 说明”列，列出具体差异字段和值；结果同时显示“物料一致 / 有差异 / 待人工确认 / 未找到对应物料 / 已列明替代料”。模型按钮显示实际分析进度与完成项数，方向提醒入口固定在工具栏右侧。Ctrl+F 聚焦搜索，Esc 收起侧栏，F5 核对，Ctrl+E 导出。

## 结论与参考信息

详情先给出最终结论和下一步建议，分别显示参考信息差异、AI 补充意见和配对依据。配对置信度不再作为醒目的百分比展示，避免被当成物料核对通过率。AI 认为一致而程序仍发现确定差异时，明确说明最终结论和冲突原因。

按确认的业务规则，“旧料号 / 原料号 / 历史料号”及对应的 Old/Previous/Legacy Part Number 列仅用于追溯，其空白或差异不影响物料一致判定。保留原始值、逐字段对照与 Excel 参考标记。空参考列与单侧参考列也能保留；已知参考表头不会被内容识别或云端角色建议误当成 MPN 或批准替代料。其他未知字段以及厂商、型号、规格、用量、位号、贴装状态仍参与检查。

参考字段从本地模型、混合核对和 AI 分析的物料比较输入中排除，避免再次被模型当成物料差异。真实的数量、参数和输入完整性冲突仍不可被 AI 放行。本地模式继续要求语言模型完成全部物料分析后才能输出和导出，失败或取消不输出规则兜底报告。

语言模型仍需在模型管理中下载并自检，`full` 安装包仍不包含 Qwen3-4B。

## 方向核对

独立方向面板可滚动查看全部元件、具体核对事项与位号，并筛选或打开物料详情。BOM 一致不代表实物方向已确认，仍需对照规格书、丝印和实物核对极性、Pin 1 与机械方向。
