# SMT-FAI 3.3.0

本地模式改为必须逐项完成语言模型分析，避免只有规则或向量候选就显示最终结果。

- **必须分析全部物料**：使用 Qwen3-4B Q4_K_M，包括一致、差异、需复核和单侧未匹配项。每批校验 ID、行数、判定和说明；截断、上下文不足或不完整回答按需拆批。单项仍失败就终止，不输出部分结果。
- **明确运行状态**：区分校验/加载与分析，显示已分析项数、请求数、耗时，可取消。缺模型、失败或取消时不生成结果、Excel 或新历史记录。纯本地不触发额外云端 AI 分析；模型自检独立于本次 BOM 使用记录。
- **保留硬约束**：程序负责解析、配对草稿、数量/位号及覆盖完整性检查；语言模型可以把原本通过的项标为需复核，但不能把已知硬冲突改为通过。行详情、历史数据及 Excel 保存本地 AI 说明和模型调用记录。
- **紧凑上传卡片**：文件区域改为两行，桌面约 44 像素，触摸布局约 48 像素；保留替换、移除、文件名和读取提示。
- **独立方向提醒区块**：汇总需核极性、Pin 1 和机械方向的元件/位号，支持展开、定位与筛选；原有方向列、详情及 Excel 提醒保留。
- **混合模式修复**：没有待云端复核的行时也会正确结束，允许导出。

升级后请在「管理 / 下载模型」下载并自检 **Qwen3-4B（约 2.5 GB）**。本地模式必需开启语言分析，旧的模型关闭设置不再绕过；四种向量模型仅为混合模式的可选辅助。`full-setup.exe` 仅预装向量模型，**不含 Qwen3-4B**。模型下载完成后，本地模式可离线分析；首次加载时间和分析速度取决于设备。

方向提醒只列出需要人工核方向的元件，BOM 一致或模型通过不能代替实物方向检查。验证范围与证据见 [验证记录](../reviews/2026-11-09-required-local-analysis.md)。
