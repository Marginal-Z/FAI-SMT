## SMT-FAI 1.2.4

- 文件导入页重新设计：顶部说明横幅和「导入文件 → BOM 核对 → 生成 FAI 坐标」三步进度；BOM、站位表 A、站位表 B 三张卡片显示文件名、条目数、大小和导入时间，可直接更换或移除；新增「文件检查结果」，逐个文件显示格式、工作表、识别到的列和结构检查；底部提示是否满足核对条件，「清空」与「开始核对 (F5)」并排。
- 核对页：顶部显示 BOM 文件名、站位表数量、核对时间和物料总数，右侧「导出 Excel」；PASS、NG、已排除物料、替代料、差异清单五张卡片带占比和进度条；新增面别（A 面 / B 面 / A+B）和核对结果筛选，搜索支持模糊匹配。
- CAD坐标页：左侧为输出文件预览表格（含封装和站位状态，可搜索），右侧为生成检查（位号匹配、重复位号、坐标有效性、面别一致性）和文件信息。
- CAD坐标功能区：坐标文件卡片（更换 / 移除）、坐标单位、CAD 格式选择与模板设置、「生成 CAD」和「核对报告」两个主按钮。
