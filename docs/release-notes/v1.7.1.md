## SMT-FAI 1.7.1

### 修复
- **移动端卡死**：手机底部导航栏打开「设置」后，再点 BOM 核对 / CAD 坐标 / PCB 导航图不会离开设置，看起来像点不动。现在点击页面标签会直接切换到对应页面。
- 修复手机上「核对规则」页的保存按钮被挤出屏幕、CAD 坐标单位卡片和「开始核对」栏溢出的问题。
- 新增手机端自动化点击测试，覆盖标签切换、设置各页面、核对页、CAD 坐标、导航图工具，以及在手机上完成新手引导。
- 工具栏图标鼠标悬停时显示功能名称（触屏长按显示）。

### BOM 核对
- 核对结果默认不展开右侧卡片，点击某一行后才显示，卡片右上角可关闭。
- 「核对结果」列移到「人工确认」之前；当前列表全部为 PASS 时不显示「人工确认」列。
- 人工确认按钮重新设计：未确认为蓝色描边「确认」，悬停变为实心；已确认显示绿色「✓ 已确认」，悬停可撤销。详情卡片中为更醒目的大按钮。
- 搜索框缩短；「开始核对 / 导出 Excel / 清空」卡片纵向加高，与导入卡片和统计卡片两排对齐，按钮上下排列不再拥挤；统计卡片与上方三张导入卡片等宽对齐。

### CAD 坐标
- 「生成 CAD / 核对报告」卡片移到右栏顶部，与下方「生成检查」上下对齐、同宽；左侧坐标文件、单位、格式卡片铺满左栏。

### PCB 导航图
- 窗口足够宽时工具栏全部横向展开显示，不再折叠；较窄时才收进「…」。

### 关于
- 关于页面重新设计：应用图标与简介、版本 / 平台标签、软件更新、信息（版本、平台、配置文件位置可复制、更新来源）、链接（官网、使用教程、更新日志、源代码，可直接在浏览器打开）、开源组件与许可。
