## SMT-FAI 1.2.6

- PCB导航图 3D 视图：「元件显示」切换为「3D 立体」后，板子按倾斜视角显示，元件有高度、受光侧壁和投影，板边可见厚度。右键拖动可旋转、倾斜视角（触屏：双指旋转，三指上下拖动倾斜）。右下角控制条可调倾角、左右旋转 15°，也可一键「俯视」或「斜视」。复位按钮会同时恢复视角。默认仍为 2D 平面。
- 元件绘制更接近实物：贴片阻容有镀锡端电极和焊接线，电阻有电阻膜，功率电感有铜端和线圈标记，二极管有阴极环，LED 有透镜，IC 有塑封边、1 脚凹点和两段式鸥翼引脚，BGA 有基板边，晶振有金属盖和角焊盘，连接器有金色针脚和卡扣槽，测试点和 Mark 点有镀层与开窗。
- 防碰撞：除同一面相邻元件外，「所有面」视图下底面元件也会为顶面元件让位，自动缩小，不再从顶面元件下面露出来。空贴（不在 BOM 中）的外框不会挤压已贴装元件。只缩小显示尺寸，坐标保持不变。
- 安卓界面缩放：按设备屏幕自动缩放。平板按 1280×800（横屏）/ 800×1280（竖屏）的布局等比铺满屏幕，大屏平板控件随之变大；手机保持设计尺寸。「设置 → 外观 → 界面缩放」可改为 80%–150%，桌面端同样可用。
