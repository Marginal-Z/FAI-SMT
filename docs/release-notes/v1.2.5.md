## SMT-FAI 1.2.5

- PCB导航图：元件坐标保持不变，相邻元件的估算外形会按需收缩，同一面不再互相重叠（只收缩朝向相邻元件的那一边；按封装代码得出的尺寸最后才收缩）。同一位置的替代封装保留原样，已贴装的元件画在上层。位号文字被上层元件遮挡时自动隐藏，不再叠在别的元件上。
- PCB导航图新增「立体」显示：元件按高度抬起，带侧壁和阴影。功能区「元件显示」、全屏浮动按钮和「设置 → 导航图配色」都可切换，默认扁平。
- 流畅度：缩放、平移和鼠标悬停只重绘画布，不再重建整个页面；元件外形和位号排版只计算一次后缓存；底面变暗改为整层处理。Android 端请求屏幕支持的最高刷新率（如 90/120/144 Hz）；Windows / Linux 按显示器刷新率渲染。
- 核对结果新增人工确认：每行可点「确认」，表头可一键确认当前列表全部项目；展开行可查看确认时间并填写备注。新增「确认状态」筛选，结果卡片显示已确认数量。导出的 Excel 报告增加「人工确认时间」和「确认备注」两列。NG 项全部确认后，生成 CAD 时不再弹出 NG 提示。
- 平板竖屏：核对页搜索框单独一行，筛选项排在下一行。
