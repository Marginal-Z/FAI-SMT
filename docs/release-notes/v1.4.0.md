## SMT-FAI 1.4.0

### 升级安装（重要）
- **Android**：从本版本起，所有 APK 都用同一个正式签名密钥签名，以后每个新版本都能直接覆盖安装，不会再出现「签名不一致 / 与现有软件包冲突」的问题。旧版本（1.3.0 及以前）是用每次构建临时生成的调试密钥签名的，**需要先卸载一次旧版本再安装 1.4.0**（核对规则等设置会被清除），之后的版本都可以直接升级。所有 APK（各架构包和通用包）现在使用同一个版本号，切换安装包不会被判定为降级。应用内更新会在安装前比对签名，不一致时会给出明确提示。
- **Windows**：新增安装程序 `SMT-FAI-1.4.0-windows-x64-setup.exe` / `-arm64-setup.exe`。按当前用户安装，不需要管理员权限，带开始菜单快捷方式和卸载项。新版本会覆盖升级到原安装位置。用安装程序安装后，应用内更新会自动下载并静默运行新版安装程序，完成后重新打开软件。仍提供 zip 绿色版。
- **Linux**：.deb 包名与版本号连续，可直接 `apt install ./SMT-FAI-*.deb` 覆盖升级。

### 新手引导
- 引导扩展为 22 步，每一步自动打开对应功能并高亮实际控件：导入 BOM / 站位表、文件检查、开始核对、核对结果分类、筛选、明细与人工确认、导出报告、坐标文件、单位与格式、输出预览、生成 CAD、PCB导航图画布、视图操作、2D / 3D、着色方式、元件库、使用说明和帮助按钮。
- 没有导入文件时自动使用内置示例数据演示每个页面，引导结束后自动清除。提示框显示当前所在功能和进度，并会根据位置自动放在目标的下方、上方、侧边或内侧。

### 首页美化
- 顶部横幅加入「导入文件 → BOM 核对 → 生成 FAI 坐标」进度，点击可跳转。
- 导入卡片加入柔和阴影；下一个需要导入的卡片带「下一步」标记；拖放区按文件类型着色，图标更醒目。
- 文件检查表格改为隔行底色。底部改为逐项显示 BOM、站位表 A、站位表 B 的导入状态。
