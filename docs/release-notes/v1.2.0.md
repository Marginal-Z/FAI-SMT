## SMT-FAI 1.2.0

- 新应用图标（FAI 首件测试设备造型）。
- 设置：主题、语言，以及检查更新 / 应用内更新（Windows、Linux 自动替换并重启；安卓调用系统安装器）。
- 差异清单：汇总 BOM、站位表 A/B、坐标文件之间的所有不一致，并说明原因与影响；导出的核对报告新增「差异清单」工作表。新增站位表描述与 BOM 不符、坐标缺失、面别不符、站位重复等检查。
- PCB 装配图（原坐标视图）：按元件类型绘制（电阻绿色、电容橙色、电感、二极管、三极管、IC、晶振、连接器、测试点、Mark 点），按封装推算实际尺寸；放大后位号显示在元件内部；支持 TOP 面 / BOT 面 / 所有面、镜像、左右旋转 90°，可切换按元件类型或核对结果着色。
