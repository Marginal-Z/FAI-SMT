## SMT-FAI 2.0.0

2.0 是一次重构：软件只做 BOM 与 BOM 核对，以及可选的 AI 核对。

### 只做 BOM 核对
- 移除 PCB 导航图、CAD 坐标生成、站位表、核对规则、排除规则和元件库。
- 三张导入卡片：**单 BOM**（基准）、**A-BOM 文件**、**B-BOM 文件**（可选）。A 与 B 先合并（同一料号用量相加、位号合并），再与单 BOM 逐料号核对；只有 A-BOM 时直接核对。

### 按内容识别列
- 料号、物料描述、用量、位号按单元格内容识别，不依赖表头名称；表头写法不同或没有表头都能读取。
- 品名 + 规格等多列描述自动拼接；只有位号的续行归到上一个料号；重复料号合并。
- 名称不同或无表头的其他列，按内容与单 BOM 的列自动配对。
- 鼠标停在导入卡片的状态上，可查看每一列的识别结果，以及用量与位号不符、位号重复等提示。

### 核对规则
- **物料描述**只比较英文字母与数字组成的参数（区分大小写，顺序不限）；中文名称多一个字、少一个字或一长一短都视为一致。
- **用量、位号以及两边都有的其他列**必须百分之百一致。
- 结果分为一致、有差异、仅单 BOM、仅 A+B；差异单元格填色，不同的字符加粗高亮；位号列出缺少、多出及挂在其他料号下的。
- 点击一行，右侧逐列对比单 BOM 与 A+B 的值。

### AI 核对
- 核对页新增「AI 核对」开关；接口在「设置 → AI 核对」中配置。
- 支持 OpenAI 兼容接口（OpenAI、DeepSeek、通义千问、Kimi、Ollama、vLLM 等）和 Anthropic；可填写接口地址、API Key、模型，并测试连接。
- 每次核对后输出 AI 分析结果：总结与逐条发现（错误 / 警告 / 提示），AI 标记的料号以紫色标识，点击发现跳到对应料号。

### Excel 报告
- 每个料号一行，单 BOM 与 A+B 的描述、用量、位号和其他列并排；结果按状态填色，差异单元格填黄色，AI 说明填紫色；开启 AI 时附带「AI 分析」工作表。

### 界面
- 现代主题去掉渐变与光晕，图标改为扁平样式；工业主题保留。
- 新手引导、使用说明和官网按新功能重写。

### 升级说明
- 旧版本的核对规则、元件库和导航图设置不再使用，外观、语言与更新设置会保留。
