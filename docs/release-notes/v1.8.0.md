## SMT-FAI 1.8.0

### 新增工业风格主题
在「设置 → 外观 → 界面风格」中可在「现代」（原主题，默认）和「工业」之间切换，选择会被记住；浅色 / 深色 / 跟随系统对两种风格都有效。

工业风格：
- 纯白底面，所有卡片、按钮、输入框、下拉框和导航图画布都用 1 px 灰色描边，去掉阴影、渐变和背景光晕。
- 小直角（卡片 6 px、按钮和标签 3–4 px），布局更紧凑。
- 石墨黑主色：主按钮、当前页面标签、文件图标块均为 #17191C 平涂。
- 结果配色更沉稳：PASS 深绿、NG 深红、替代料琥珀、已排除灰色，标签带同色描边。
- 底部状态栏为灰色条带并带分隔线；手机端导航栏为贴底的扁平工具栏。
- Windows 上使用 Segoe UI / 微软雅黑，其他系统使用内置 Inter 字体。
- 提供深色版本（石墨灰底面）。
