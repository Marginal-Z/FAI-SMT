## SMT-FAI 1.9.0

### 核对改为按文件内容比对，不再有内置规则
- 「BOM 核对」逐个位号比对 BOM 与站位表（A + B 合并），能找出：位号缺少或多出、位号上料了无关料号、两个料号贴同一位号、同一位号出现在两面、同一面同一站位有两个料号、站位表料号不在 BOM 中、BOM 用量与位号个数不符、BOM 位号重复、描述不一致、站位数量与位号数不符、坐标缺少或面别不符。
- 替代料只从有依据的内容中读取：BOM 的替代料号列、站位表的关联料号列，以及你在替代料对照表中登记的关系。不再按「主料下一行」这样的位置判断；描述相同的料号只作提示。
- 已删除的内置判断：烧录料、无位号自动排除、默认忽略 MARK* / FID* / FM*、用量核对开关。
- 「核对规则」只保留你填写并保存的四项：排除关键字、排除料号前缀、替代料对照表、忽略位号，默认全部为空。升级时，旧版自动填入且未改动过的默认关键字和默认忽略位号会被清空，你自己改过的会保留。

### 表格按内容识别，列名不限
- BOM 与站位表的表头行和各列（料号、位号、用量、描述、站位、替代料号、关联料号、面别）由单元格内容自动判断。支持无表头、表头前有标题行、带封面页、列顺序打乱的表格。
- 识别结果可在「智能核对 → 识别结果」中查看，每列都可手动改正。

### 新增「智能核对」页面
- 三种模式：BOM 与 BOM、BOM 与单站位表（有面别列时自动分 A / B 面）、BOM 与站位表 A+B。
- BOM 与 BOM 可找出：仅一方有的料号、同一位号换了料号、用量、位号缺少 / 多出 / 改到其他料号、描述、替代料，以及两份文件共有的其他列（厂商、封装等）的差异。
- 结果可预览，并可编辑任意单元格、结果和备注；软件内显示分析报告；导出 Excel 包含核对结果、分析报告、位号对照、识别结果四个工作表。

### 新增「AI 核对」页面
- 独立功能，不参与也不改变本地核对结果。
- 把所选表格发送给 Claude（Anthropic API）或任意 OpenAI 兼容接口，显示 AI 的分析，可复制或导出为 Markdown。
- 只有在使用 AI 核对时才会上传所选文件；API Key 只保存在本机。

### 升级后请注意
- 有 Mark 点时，在「设置 → 核对规则 → 常规 → 忽略位号」中填写，如 `MARK*`。
- 需要排除的辅料、插件料，在「排除物料」中填写关键字。
- 原先写在主料下一行的替代料，需要写在站位表的「关联料号」列，或登记到替代料对照表。
