# SMT-FAI 3.2.1：DeepSeek 截断恢复、模型选择与方向提醒栏

## 云端核对修复

- DeepSeek 的结构化核对显式关闭思考模式，使用 JSON 输出；修复连接测试仅给 50 token、核对输出预算偏小的问题。
- 官方 DeepSeek 接口的默认模型更新为 `deepseek-flash`，旧的 `deepseek-chat` / `deepseek-reasoner` 配置自动映射；自定义网关保留原模型名称，其他手动指定模型保留。
- 截断时在重试次数限制内提高输出预算，仍截断的请求按行或列自动拆成更小的批次。云端与混合核对默认每批 8 项；独立 AI 分析改为按行数和输入大小分批。
- 不解析被截断的 JSON。完整回答才参与核对，单行仍失败会明确标记未完成；不把残缺回答或缺失行判为 PASS。重试和拆批保留调用用量记录。
- JSON 请求附结构示例，并处理空白 JSON 输出的重试。AI 分析仍应用隐私选项并还原料号别名，同时检查中文颜色、极性、材质等区分特征。

## 本地模型选择

- 核对页增加独立模型栏，可直接启用 / 关闭、选择四种匹配模型并查看下载状态；可进入「管理 / 下载模型」。
- 设置页使用同一选择器。支持鼠标、触摸和键盘；选择自动保存，下次核对生效，本次实际调用记录保留。
- 推理或释放旧模型时锁定切换；切换后下次推理加载新模型。修复快速切换设置时并发写入造成的选择丢失。

## 方向核对提醒栏

- 结果表格增加独立「方向核对提醒」列，显示正负极、A/K、Pin 1、缺口 / 卡扣等检查项和位号。
- 手机物料卡片显示独立提醒区，详情与 Excel 保留完整依据。BOM 一致仍需要对照规格书、PCB 丝印和首件实物检查方向。
- 修复新增横栏后手机首次引导卡片可能落到屏幕外的问题。

## 验证范围

本地完整回归 138 项通过、7 项因缺少其他模型或客户样本跳过；包含真实 Granite-Embedding-107M 推理和 390 / 800 / 1440 宽度交互。详见 [云端恢复验证](https://github.com/Marginal-Z/FAI-SMT/blob/v3.2.1/docs/reviews/2026-11-09-cloud-recovery.md) 和 [模型选择与方向栏验证](https://github.com/Marginal-Z/FAI-SMT/blob/v3.2.1/docs/reviews/2026-11-09-model-controls.md)。

DeepSeek 适配、截断恢复与故障保护通过可控 HTTP 模拟接口回归。没有使用用户 API Key，也没有验证用户实际账号或具体 BOM 的在线响应；实际效果仍取决于服务状态、模型和输入。

DeepSeek 适配依据：[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)、[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。

新版本直接覆盖安装，保留原有设置。官方 DeepSeek 旧模型名会自动迁移；本地模型开启后仍只在双侧均有未匹配项时调用，当前流程不调用可选语言模型。
