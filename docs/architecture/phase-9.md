## 测试体系

| 测试 | 内容 | 位置 |
| --- | --- | --- |
| 开发生成器（读表） | 1000 个随机布局：语言、表头写法、无表头、标题行、列顺序、无关列、拆分描述、续行、四种料号体系、厂商 / 厂商料号 / 替代料 / DNP / 层级 / 整列备注 | `test/support/bom_gen.dart`，`tool/eval_read.dart`，`test/dynamic_read_test.dart`（下限只升不降） |
| 注入变化（核对） | 300 组：换布局、换语言，每个物料注入一种变化（换单位写法、拆行、改参数、改用量、少位号、改厂商、删除、新增、换料号、换料号并登记替代），检查结果与注入一致 | `test/support/mutate.dart`，`test/injected_changes_test.dart` |
| 无料号无位号匹配 | 40 组换料号、去位号、换语言的采购 BOM，真实向量模型 | `tool/eval_semantic.dart` |
| 留出生成器 | 独立编写、调参时未使用：采购 BOM（无位号）、多层级整机 BOM（含结构件、包装件）、带厂商列的 PCBA BOM；日语、韩语、西班牙语、英语；修订版换布局并注入改值、改用量、删除、新增 | `test/support/holdout_gen.dart`，`tool/eval_holdout.dart` |
| 云端校验 | 诚实 / 不诚实的模拟云端、失败、截断、编造引用 | `test/hybrid_test.dart`，`test/cloud_full_test.dart`，`test/modes_test.dart` |
| 真实 BOM（人工确认答案） | 每个案例一个文件夹：两份 BOM + `expected.json`（逐行确认结果和确认人）；放在 `samples/realworld/`，不进仓库 | `tool/eval_realworld.dart` |
| 本机真实文件回归 | 用户的 CY028 文件（不进仓库） | `test/real_samples_test.dart` |

CI 每次推送都运行全部测试，并在「Evaluation」步骤生成读表与留出生成器的评估报告（显示在运行摘要中，并作为构件保存）。
