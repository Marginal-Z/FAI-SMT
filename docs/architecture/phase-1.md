## 发现的问题（进入阶段 2）

1. **纯数字料号被当成数字**（如 `460100030`）：料号列识别不到，无表头时只有约 70%。T100 的真实 BOM 就有这种料号。
2. **品名、规格分两列时只识别一列**（拆分描述只有 15.3% 完整），表头不在词典里时尤其如此；另一列被当成「其他列」做精确比较，会造成误报。
3. **泰语 BOM 偏低**（料号 74.3%）：表头词典没有泰语，全靠内容。
4. 合并单元格、多层级、DNP / 选配 / 替代标记、物料类别目前都没有识别。
5. 引号内含换行的 CSV 字段会被拆成两行。

以上都由阶段 2 的动态识别处理，并以本页基线衡量改进。
